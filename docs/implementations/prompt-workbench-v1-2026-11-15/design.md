# Prompt工作台V1实施设计

基于2026-11-15现有源码。PromptRegistry已具备不可变模板、调用级请求与响应捕获；评测中心已有只读发现，不重新建立运行事实来源。

布局为左侧220px节点目录，右侧版本卡片和四个主Tab。白色#FFFFFF、底色#F5F7FA、主文#243247、边框#DCE3EC、强调蓝#315FD5、次文#65758B。系统中文无衬线用于界面，等宽仅用于Prompt与JSON编辑。统一左对齐，用一块大编辑区承载主要操作，不添加装饰统计卡片。

审查后舍弃通用卡片墙：顶部只显示有真实来源的当前运行时版本卡片，未绑定即unknown。草稿与线上版本区分。四Tab与左右节点目录均写入URL便于刷新。

新增隔离调试服务：复用现有Provider和Registry调用捕获，手工测试输入与输出JSON Schema，或显式读取有权限的历史调用作为测试输入；执行不触发Workflow、HITL或Engine，不发布Prompt。编辑覆盖仅限System与测试User文本；固定组合源码只读，不伪称已经安全编辑动态服务代码。调试草稿登记为admin_debug_draft来源，不冒充runtime_source_verified。

版本Diff既显示保存的文本变化，也允许两个真实快照对同一输入分别调用。每次调用有独立Call ID；两个版本结果不自动解释为因果或质量提升。调试测试标签与Call关联独立元数据，不创建Trace Root或业务执行事实。关联页区分调试用例与历史调用；没有精确证据的评测案例关联显示未采集，不推断。

写入/调试复用现有Admin和标注权限；完整历史请求读取复用快照权限。本地测试模式沿用loopback校验。凭证不保存到浏览器存储。不更改生产Prompt、模型配置或业务状态权威。
