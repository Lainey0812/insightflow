# 通用口径登记与版本绑定 V1

本次首先提供一个通用且受控的登记入口：实际聚合字段、函数和空值/计数依据由代码生成，不让用户或模型伪造；用户可声明记录粒度。未知始终保留未知，不猜测业务实体、币种、税费或退款定义。

初始/删除任务的新计划在同一业务事务登记不可变口径侧车。不改历史 PlanVersion、Approval 或 Execution 原始载荷。修改粒度声明产生新计划版本、重新校验并清空当前批准；不编辑聚合操作和原始意图。若选择“每行一个实体”，必须指定画像中非空且全局唯一的标识字段；否则拒绝，不能用声明消除重复。明细/记录声明不等于实体计数，去重仍取决于真实 distinct_count(field)。

计划原有约束和 defer/clarify 阻断继续执行。新模块不冒充通用自然语言歧义识别器，也不新增所有请求必须填写的问卷。现有确认按钮批准当前已经展示的实际计算方法；未主动声明的业务粒度在批准快照中仍为 unknown，不能称为已确认实体含义。

口径计划侧车及批准副本使用同一业务 SQLite 外键与不可变触发器；批准副本与现有审批原子写入。Engine核验当前计划侧车与批准副本精确一致，新侧车缺少批准副本时拒绝执行；旧计划无侧车保持兼容未知。记录随执行元数据传递到报告与导出。

后续未实现：任意公式/单位转换、在此修改字段和函数、复合实体标识、业务粒度的LLM自动推断。需要调整计算或存在原有阻断歧义时重新提出明确需求，不能只勾选确认绕过。
