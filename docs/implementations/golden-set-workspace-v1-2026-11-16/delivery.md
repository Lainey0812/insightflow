# 黄金数据集工作区 V1

2026-11-16，REQ-0158。仅新增Golden管理工作区，不改变已冻结的旧基线文件或历史评分结果。

## 两个子页面

- `/evaluations/golden`：当前冻结数据集。顶部卡片展示Set ID、V版本、测试用例数、源数据记录数及冻结标记。版本筛选可查看任一真实历史版本；用例与源数据均为表格，支持分页；没有增删改入口。可导出包含精确版本/哈希/文档的JSON快照。
- `/evaluations/golden/draft`：可对测试用例与源数据进行新增、编辑、删除。用例编辑包含原始需求、数值Oracle、必须/禁止行为、通过标准和错误对照等；记录JSON编辑保留文本/数值类型。字段列表保持现有结构，本轮不提供增删字段。操作先改变本地Draft，填写操作者后保存；每次保存保留不可变修订。
- 保存成功后，确认人工核对并填写变更说明，点击发布。服务端在单一业务事务创建下一版、切换current、重置Draft基准。页面自动回到新版本；旧版不可变并继续可选。未保存内容、编辑未完成、未确认等条件会禁用发布。未修改或空集发布由服务端明确拒绝，不产生虚假版本。
- 冲突保留本地修改，允许明确“放弃本地修改并重新载入”。错误不会被当成成功。

## 持久化与接口

独立受控目录 `data_dir/golden_sets/golden.sqlite3`，目录0700、文件0600，SQLite实际启用外键。此前没有可写Golden版本仓，因此不复制现有只读发现服务作为写入事实来源。

表：golden_versions（冻结版本）、golden_draft_history（每次保存的Draft）、golden_head（当前版本与Draft指针）、golden_workspace_migrations（v1）。版本与Draft历史有UPDATE/DELETE拒绝触发器；head的版本/修订外键指向实际快照。原业务库/Trace/Registry及旧表不变。

- GET /admin/golden-set?version=N：选择版本与元数据列表；GET不进行发布或编辑。
- GET /admin/golden-set/draft：读取Draft。
- POST /admin/golden-set/draft：完整保存，校验expected_revision、Set归属和文档结构。
- POST /admin/golden-set/publish：校验revision/base_version，BEGIN IMMEDIATE事务冻结下一版并切换指针。

读取复用Admin权限，写入需标注权限；本地测试模式沿用loopback限制。没有客户端路径、API Key或任意文件写入入口。源文件或版本仓初始化失败仅使该Admin功能不可用，保留既有业务启动。重复初始化不重复登记；并发发布只有一个成功，另一个409，避免重复新版本。

文档验证：唯一case_id、精确case_count、唯一非空列、行字段一致、严格非布尔数值Oracle、禁止NaN/Infinity，最多500用例/5000行、文档2MB。Draft可暂为空以支持删除，但不能将空用例或空源数据发布为冻结集。内容哈希使用稳定排序JSON；原文件字节哈希另存，不混作版本号。
