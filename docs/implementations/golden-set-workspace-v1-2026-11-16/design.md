# 黄金数据集工作区 V1设计

来源审计：现有golden-set.json是5用例9行的固定历史基线，没有version冻结声明；DatasetRegistry为只读发现，load_golden旧评测器限定5例9行。不能覆盖原文件、伪造旧版部署或改变旧评测口径。

新增受控Golden版本仓，以已配置真实来源作为当前工作区初始v1（现在登记冻结，不冒称历史冻结）。版本和Draft每次保存内容均以追加快照保留，只有head/Draft指针可变。确认发布通过同库事务创建vN+1并更新current和重置Draft。输入结构验证、唯一case_id、数值Oracle和行结构检查、revision CAS、来源哈希及版本哈希均保留。权限复用Admin只读/标注写入；原文件不写回。

两子页：当前版本顶部一个版本/用例数/源数据数卡片、版本选择器、只读用例表与源数据表；Draft用相同表格增加添加/编辑/删除，保存草稿后确认冻结下一版。脏草稿不允许直接发布。页面沿用蓝白管理台，不新增框架。所有历史来源/冻结信息真实显示。

边界：本轮管理工作区的current不是把旧CLI硬编码五用例评分器静默替换；旧评测与发现API继续读原基线，UI说明新版本尚未自动接入旧评测器。提供冻结版本JSON导出以保存精确输入；未来评测调度必须显式绑定版本/哈希。不会自动启动LLM或重评分历史Run。
