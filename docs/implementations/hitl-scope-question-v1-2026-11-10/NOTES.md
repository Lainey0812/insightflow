# HITL 范围对齐（REQ-0120）

## 修改依据

REQ-0120。用户要求：方案里的名称有歧义时，在确认阶段与用户对齐，或在这里补充范围。不要让用户回到最初的需求里写死完整取值。

## 实现

审核结果新增 `scope_questions`。某个筛选词尚未核对或与步骤不一致，且每个分析方向在汇总前都只用它做过一次文本筛选时，确认页第 04 节给出范围确认。模型如果把这个词扩成多个名称，只要其中有一项与原词相同或互相包含，仍可在这里对齐。

用户先预览上传数据里的完整取值，再保存。保存替换模型猜测的名单，生成新计划版本，并重新审核。勾选不能跳过。确认按钮在审核通过后才可点，保存本身不执行分析。

与原词无关的筛选名单不会变成范围问题，预览返回 409。自由文本修订仍返回 `AI_REVISION_NOT_AVAILABLE`。核对期间底部输入框保持锁定，提示到上方对齐；更换目标仍用「重新提出需求」。
