## 数据契约与实现

TaskExecutionMetadata 新增可选 sample_statistics，默认 None。来源为已经批准、已经加载指定数据版本、复用既有规范化/筛选/派生后的真实聚合输入视图。

恰好一个聚合步骤时记录：聚合 step_id、聚合前行数、关键字段引用及显示标签、各字段缺失数、按行去重的联合缺失数、联合完整数，各指标函数、来源字段、计数依据和非空参与记录数。关键字段定义为分组字段和聚合字段并集，不冒充业务主键。长标签截断到1800字符，不使原本合法的计算因新增元数据失败。

count() 为行数；count(field) 为非空数；distinct_count(field) 为非空不同值数，参与记录数可以大于去重结果。不对缺失记录自动删除，不修改原聚合结果。完整数+缺失数=聚合前行数；新增 Schema 校验防止计数、函数或依据冲突。

多次聚合、无聚合、失败任务不声明原始行联合完整性；无字段 count() 的完整性不适用。Top N 结果行数与聚合输入数明确分开。

这些事实通过既有执行持久化原子保存，不新增数据库表或第二套执行器。报告继续从 ExecutionResult 复制元数据；页面与 HTML 从同一保存事实读取。多方向即使计数相同也不合并集合；旧报告保持未知，不后台重算或回填。
