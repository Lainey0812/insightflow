# 节点详情读取已有参数（REQ-0128）

详情页按节点去读 InsightFlow 里已经存下的参数，不新造 Token、URL 或检索切片。

大模型节点打开 Prompt & Model 时，若调用摘要标明原文仍保留，就用现有的模型快照接口读取拼装后的消息和原始返回。本地测试模式允许空凭证。消息按 system、user 分条展示，避免整段 JSON 截断后把用户消息切掉。单条超过 12000 字才截断。若服务返回 403，仍保留原来的凭证表单。Temperature、Max Tokens、Token 数和预估成本没有写入调用参数时继续显示未采集。

数据画像节点的 API 页读取数据集画像接口。展示文件格式、行数、列数、表头行、编码、分隔符，以及字段名、逻辑类型和缺失数。不展示字段样例值。

规则节点和工具节点的 Output 带上这条 Workflow 观测里已经关联的执行、计划版本、审批、报告和报告生成记录，按节点上的 execution_id、plan_version_id、approval_id、report_id 对应。非 span 起止事件会展开已保存的事件字段，例如校验规则和候选状态。执行结果表、完整计划和完整报告不在这条观测接口里，业务读取接口对当前 Admin 会话返回 403，所以这里不补造那些正文。
