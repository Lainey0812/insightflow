# Chat Workspace V1 — 实施前设计

需求档案 REQ-0069。复用真实会话、计划审核、报告及查询接口；仅调整主工作台与前端交互锁定，不修改后端或 LLM。

## 设计方案

颜色：纸白 #ffffff（聊天画布）、薄雾 #f3f6f4（左侧记录）、墨色 #1d2925（正文）、灰绿 #697b74（次要信息）、深青 #176b55（主要操作）、暖琥珀 #9b6c25（等待与风险）。保留可辨别的错误红，仅用于真实失败。

字体：Avenir Next 负责拉丁文字与品牌，PingFang SC/微软雅黑负责中文；正文 14–15px、聊天行高 1.9，欢迎标题 30–36px，记录标题 13px。系统字体不发起远端字体请求。

布局：桌面左侧 260px 固定记录栏，右侧主聊天区；聊天正文/输入框同一条最大 780px 中轴，正文左对齐，用户内容收在右侧浅色气泡。窄屏将左侧变为可打开的抽屉。

```
┌──────────────────┬──────────────────────────────────────────┐
│ InsightFlow      │ 本次咨询标题                 服务连接状态 │
│ ＋ 新建分析      ├──────────────────────────────────────────┤
│                  │                  用户需求与文件           │
│ 咨询记录         │ InsightFlow 的回复                       │
│ · 当前咨询       │ [真实当前步骤：生成分析方案]               │
│ · 历史咨询       │ [方案审核 / 报告链接，仍在对话里]          │
│                  │                                          │
│ 本地工作空间     │ [上传附件    输入业务问题          发送]   │
└──────────────────┴──────────────────────────────────────────┘
```

特征：像一个业务问题的讨论空间，不是数据监控看板。一个主色、一条对话中轴；重点是“需求—方案确认—真实结果”，不生成装饰性 KPI。步骤只显示当前保存状态的一句反馈，不画假进度百分比或补全节点勾选。

## 对照需求后的修订

移除旧页面的大面积紫色渐变、英文眉题、三张营销卡片和编号流程装饰。保留可点击的三个问题示例，但收为紧凑建议，避免占据聊天区。主要个性放在细致的对话排版、深青操作色和文件/方案的清晰语义上。

运行锁定使用真实 Session 活跃状态（包含 PREPARING）、前端请求中及当前已批准分支的 queued/generating 报告状态；不只依赖一次 HTTP 的 busy。阻止表单、Enter、附件、拖放和重复发送；运行期间锁定新建/切换，保留当前任务用于轮询恢复。Clarify 等待用户补充时恢复输入；待审核/已完成采用明确的只读输入区，不添加未实现的 AI 修订能力。

当前步骤从保存的 Session/ReportGeneration 得出，表示业务活动，不声称每个节点已采集 Trace。历史报告不强制下载，继续使用既有预览/可选下载。
