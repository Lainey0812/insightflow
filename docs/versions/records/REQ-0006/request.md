我们进入data profiler的阶段。

#

## 目标

实现真实、确定性、可测试的数据画像模块，供后续 Analysis Planner 使用。

## 开发范围

1. 支持单个 CSV / XLSX 文件和单个工作表。
2. 实现文件解析与结构校验。
3. 为每列生成稳定的内部字段 ID。
4. 识别基础 Physical Type 和 Logical Type。
5. 计算行列数、缺失数、缺失率、唯一值数和字段样本。
6. 检测疑似重复、类型混杂和结构异常。
7. 输出并校验 DatasetProfile。
8. 提供 Data Profiler 的后端调用接口。
9. 编写正常文件、空文件、混合类型、重复列名、多 Sheet 等测试用例。

## 本阶段不实现

- LLM 字段语义识别。
- 全量行级语义抽取。
- 自动数据清洗。
- 业务分析任务规划。
- 图表与分析报告生成。

## 工程要求

复用已经搭建的工程目录、数据模型和 API 约定，不重复创建项目。

将 Data Profiler 设计为独立的业务模块，由 Workflow Orchestrator 调用，不需要独立的 Agent Runtime。

所有统计指标必须通过代码从实际数据计算，不得使用模拟值替代真实结果。

## 验收标准

使用测试 Excel / CSV 能生成正确的 DatasetProfile；异常输入能够返回明确错误；自动化测试通过；画像结果能够关联数据集版本，并被后续模块读取。

请先检查现有工程结构，提出需要新增或修改的文件及实现步骤，再开始编码。
