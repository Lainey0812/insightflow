## 根因与处理

- “按团队计算”作为真实维度表达核对group_aggregate，不再因缺少“统计/汇总”关键词拒绝。
- “按平均值/中位数/总和排序”只在当前操作链存在唯一匹配指标时绑定，不猜测多个候选。
- “仅分析”前缀优先于“仅”，修复“已完成任务”的完整值解析；仍要求唯一、未截断、真实类别值。
- “任务数量”支持明确实体上下文的上传行数count，并在计划明示“非去重实体数”；真实数量列、非空/去重计数不能冒充行数。
- 禁止原因/绩效推断识别为受控报告表达边界，proof与执行字段条件分开。运行时再次校验受控生成版本；建议限来源/缺失核查，摘要及图表标题不用自由任务标题。
- 禁止利润分析核查真实字段、别名及操作能力；缺少利润字段不再构成无谓阻断，实际利润引用或未知派生仍拒绝。独立导入报告入口也执行相同检查。
