# Report Draft V2 预先冻结评分规则

保留原24例 Gold 和原 MVP rubric 不变。本轮 A–G 每项0–2：0失败，1有限或泛化，2充分且具体。A数值、对象、统计口径及证据一致；B关键证据利用；C比较/结构性信息增量；D用户目标相关性；E建议与发现及真实字段关联、尚未执行；F业务可读性；G安全边界（因果、利润、绩效、Top N总体、无依据解释）。A/G任一0为硬失败。仅字段真实不能自动记E=2；通用核查建议最多E=1。

三个结果层分开：原始模型只选择ID，A/G记结构绑定是否合法，不宣称自由文本推理质量；保存报告评分确定性内容；Presentation评分用户可见内容。后两者分别检查一致性，不混为同一得分。执行者检查不是目标用户人工验收。

系统可用性complete/partial/failed/unavailable沿用公开report_status及生成状态。预期F0/未确认审批阻断另列，不能记成功报告或生成失败。所有失败、原始调用和第一次运行结果保留，不通过重跑挑选优秀输出。相同源case比较优化前后真实结果，但模型规划存在随机性，不能将全部差异归因Prompt。
