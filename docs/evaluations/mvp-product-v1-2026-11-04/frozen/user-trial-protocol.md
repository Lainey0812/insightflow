# 目标用户试用协议（待开展）

招募 3–5 位不具备 Python、SQL 或专业 BI 使用能力的销售、运营、人力或客服业务人员。每人完成一项明确目标任务与一项探索任务，使用合成数据。

主持人先说明上传、需求输入、方案确认和报告位置，不指导选择字段、统计口径或解释结果。遇到问题先记录用户行为；需要帮助时记录帮助内容与次数，不能计为独立完成。

记录表：用户匿名编号、岗位、任务编号、开始/结束、独立完成与否、帮助次数、等待时长、卡住阶段、原话反馈。

审批后请用户复述：分析什么、用哪些数据、统计什么、系统不能回答什么。报告后请用户指出主要发现、适用范围、一项局限，并定位一条结论的计算依据。

试点观察目标：至少 80% 任务无需主持人干预完成；每个用户能说清关键范围与指标，且没有将 Top N 误解为总体。小样本只用于定位问题，不作为企业收益或生产准确率证明。任一信任硬失败优先阻断扩大试用。

目前没有招募记录或用户反馈，全部待开展。
